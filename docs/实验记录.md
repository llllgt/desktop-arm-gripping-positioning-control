# 实验记录

初次验证：2026-10-07；接触摩擦修正及新增工况验证：2026-10-08。设备：Windows 笔记本，Ryzen 5 5600H、约 16 GB 内存、RTX 3050Ti。物理仿真用 CPU，视频渲染使用图形环境。所有结果是软件模型实验。

## 1. 默认搬运

输入：30 × 24 × 20 mm、30 g 工件，从 (170,-50,65) mm 转移至 (170,60,65) mm；40 mm 抬升净空；工具俯仰 1.3 rad；关节限速 0.8 rad/s、限加速度 1.5 rad/s²。

`results/native/summary.json`：仿真周期 12.342 s，最终三维位置偏差 0.5693 mm，最大抬升 39.9445 mm，TCP 跟踪 RMS 1.9026 mm。1235 个采样中，529 个存在工件与新接触垫接触；没有记录到非预期托座/地面接触。工件没有附着约束、没有被逐帧移动，执行器总关节力矩限制 ±2 N·m。

![测量曲线](../results/native/performance.png)

成功标准：最终位置偏差 < 8 mm，且工件最大抬升 > 24 mm。跟踪误差由实际工具中心与指令运动学位置之差计算；放置偏差由最终工件中心与目标中心之差计算。这些量不同于实机重复定位精度。

## 2. 轨迹与模型对照

| 场景 | 最终位置偏差 / mm | TCP RMS / mm | 结果 |
|---|---:|---:|---|
| 五次轨迹 + 偏置补偿 | 0.569 | 1.903 | 完成 |
| 三次轨迹 + 偏置补偿 | 0.509 | 1.722 | 完成 |
| 五次轨迹，无偏置补偿 | 0.601 | 1.975 | 完成 |
| 去除新附件接触模型 | 109.929 | 1.904 | 未完成 |

默认五次轨迹的依据是段端速度和加速度为零。当前单一场景下三次轨迹的位置误差更小，因此不声称五次轨迹提升了定位精度。偏置补偿在这个轻负载模型中改善有限，也不应夸大为显著控制性能提升。

去附件实验同时改变了夹持几何和接触面；该消融仅表明当前任务依赖所设计的接触配置，不是新夹指优于真实原装夹指的实测结论。未优化原装夹指的抓取宽度、姿态和任务参数。

数据：`results/benchmark/summary.json` 与各场景目录下的 CSV。

## 3. 参数扰动

固定随机种子 `20261007`，10 组输入：质量均匀分布 20–50 g、接触摩擦 0.8–1.2、初始 x/y 偏移各 ±2 mm。2026-10-08 修正摩擦后重跑，10 组均满足上述成功标准，最终位置偏差 **0.376–2.613 mm**。

旧版本的 0.358–2.916 mm 来自未实际生效的摩擦扰动：MuJoCo 在垫与工件 geom 同优先级时取最大摩擦，工件的 1.2 覆盖了较低输入。现改为显式 contact pair 并记录实际接触摩擦；默认场景 μ=1.2 的结果保持一致。受影响结果已更新，旧记录可从 Git 历史追溯。说明与新增 48 组实验见 [工况评估](工况评估.md)。

样本少、范围有限、接触模型相同；不推断实机可靠性、工业鲁棒性或任意工件适应能力。

## 4. 结构校核

参考工况：铝背板一短边全固定，另一短边承受 6 N 均布力；E = 69 GPa、ν = 0.33，线弹性小变形。该固定方式是参考简化，并不等于实际胶粘支承。

| 网格 / 公式 | 端部挠度 / mm |
|---|---:|
| 34944 四面体 | 0.04607 |
| 69888 四面体 | 0.04830 |
| Euler–Bernoulli 梁理论 | 0.05458 |

细化后挠度变化 4.84%，与梁理论差异 11.51%；线性四面体偏硬和全固定三维边界可能影响结果。根部名义梁应力 16.71 MPa，FEM 最大等效应力 15.26 MPa，力平衡残差约 4.75 × 10⁻¹⁰ N。可作尺寸量级校核，不能声称整个附件设计已充分验证。

未覆盖胶层剥离、TPU 非线性、疲劳、装配误差、打印材料各向异性。完整数据及图见 `results/structure`。

## 5. ROS 2 实际通信

官方 Jazzy Windows 运行时 + 单独构建的 control_msgs。`scripts/verify_ros.py` 启动独立仿真控制进程和任务进程，通过 DDS 传输标准轨迹与夹爪 action。

`results/ros2/summary.json`：搬运完成，最终偏差 0.5650 mm，最大抬升 39.9496 mm，1355 次关节状态采样。总计 13 个被执行的机械臂 action，其中 1 个为取消验证，12 个为搬运状态。包括启动及验证阶段的仿真时间 13.550 s，墙钟时间约 69.8 s；当前 Windows 定时回调运行慢于真实时间，不声称 500 Hz 实时控制性能。ROS 回调与进程调度使重复运行的采样数和完成时间略有变化。

`action_checks.json` 验证了：6 种本地非法轨迹、DDS 非法机械臂/夹爪目标拒绝、机械臂重叠目标拒绝、运行中任务取消。取消后保持测量位置。

节点发布实际工具和工件姿态，而非固定单位四元数。轨迹接口是项目自写的仿真 action 控制桥，未使用 ros2_control 插件。当前子集接受以零时刻开始的四关节采样位置轨迹，用位置线性插值驱动模型；没有实现 FollowJointTrajectory 的全部容差和实机驱动语义。

## 6. 自动验证

23 项 Python 测试通过：原有 12 项涵盖 100 组正解与独立 MuJoCo 变换核对、500 组逆解回代、雅可比有限差分、两类轨迹约束与端点条件、任务连续性、真实接触搬运与力矩限制、CAD/URDF/MuJoCo 附件尺寸质量惯量一致性、有限元刚体模态/恒应变与力平衡/载荷线性比例。新增 11 项涵盖 8 类非法任务参数、默认/不可达路径、低高度路径相交，以及低摩擦实际生效并导致重负载搬运失败的回归验证。

另有上述实际 DDS action 验证。未完成实物加工、试装、机械臂硬件测试或 Gazebo/MoveIt 集成。
